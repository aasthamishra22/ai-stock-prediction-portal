# AI-Powered Stock Prediction Portal

A full-stack web application that predicts stock prices using a deep learning LSTM model integrated with a Django REST Framework backend and a React frontend.


##  Tech Stack

### Backend
- Django
- Django REST Framework
- JWT Authentication
- Keras (LSTM Model)

### Frontend
- React (Vite)
- Axios
- Context API
- Protected Routes

---

##  Key Features

- User Registration & Login with JWT Authentication
- Secure REST API integration
- LSTM-based deep learning stock prediction model
- Real-time prediction results displayed on dashboard
- Modular full-stack architecture

---

##  Machine Learning Integration

- Pre-trained LSTM `.keras` model
- Backend loads model and processes stock data
- API returns predicted results dynamically

---

##  Project Structure

backend-drf/  
frontend-react/

---

##  Setup Instructions

### Backend
```
cd backend-drf
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend
```
cd frontend-react
npm install
npm run dev
```
