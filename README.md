# 📈 Stock Prediction Portal

AI-powered full-stack web application that predicts stock prices using a pre-trained LSTM deep learning model, built with **React** frontend and **Django REST Framework** backend.

---

## Project Overview

This repository contains a stock prediction portal where users can:

- Submit stock symbols for prediction
- Receive future price forecasts using an LSTM model
- Interact with a responsive user interface built in React
- Communicate securely with the backend via REST APIs

This project demonstrates full-stack development with machine learning model integration.

---

## Key Features

✔ Full-stack architecture with Django (REST API) and React  
✔ Integration of a pre-trained LSTM deep learning model (Keras)  
✔ Secure API endpoints using JWT authentication  
✔ Frontend built with modern React components  
✔ Cross-origin communication enabled with CORS  
✔ Real-time prediction endpoint for stock price forecasting

---

## How It Works

The frontend sends a stock symbol to the backend API.
Backend loads the pre-trained LSTM model (stock_prediction_model.keras) using Keras.
Model predicts future stock price(s) based on historical data input.
Prediction results are returned to frontend and displayed dynamically.
